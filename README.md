# Data Analytics Portfolio

Портфолио проектов по Data Analytics, BI и Data Engineering.

Проекты охватывают полный цикл работы с данными: от сбора, подготовки и контроля качества до моделирования, аналитических витрин, визуализации и интерпретации результатов.

## Цель портфолио

Продемонстрировать практические навыки решения задач полного цикла:

- сбор, загрузка и преобразование данных (ETL);
- проектирование DWH и моделирование данных;
- контроль качества данных и проверка согласованности;
- исследовательский и статистический анализ;
- разработка аналитических метрик и витрин;
- визуализация данных и BI-отчётность;
- формирование выводов и рекомендаций.

## Навыки и технологии

- Языки и обработка данных: Python, SQL, Pandas, PySpark, NumPy, SciPy
- Хранилища и архитектура DWH: PostgreSQL, ClickHouse, ODS/Core/Marts, Data Warehousing, Data Modeling, Fact and Dimension Tables, Incremental Loading
- ETL/ELT и оркестрация: Apache Airflow, dbt, ETL/ELT Pipelines
- Качество и наблюдаемость данных: Data Quality, Data Validation, Data Reconciliation, Data Lineage, OpenLineage, OpenMetadata
- Аналитика и визуализация: EDA, Data Analysis, Product Analytics, Statistical Analysis, Hypothesis Testing, Time Series Analysis, Feature Engineering, Matplotlib, Seaborn, BI, Apache Superset
- Среда разработки: Jupyter Notebook, Git
