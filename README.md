# Data Analytics Portfolio

Портфолио проектов по Data Analytics и Product Analytics.

Каждый проект представляет собой законченный аналитический кейс с полным циклом работы с данными — от получения данных до подготовки выводов и рекомендаций.

## Цель портфолио

Продемонстрировать практические навыки решения аналитических задач полного цикла:

- сбор и подготовка данных;
- контроль качества данных;
- исследовательский анализ;
- статистический анализ;
- разработка аналитических метрик;
- визуализация результатов;
- формирование выводов и рекомендаций.
